# 待ち時間ゲーム「餃子タワー」設計書(小変更)

日付:2026-11-20 / 親設計:`2026-11-17-mogiten-order-design.md`

## 目的
注文の待ち時間を楽しく過ごしてもらう。メニュー画面からも遊べる。

## 決定事項(ユーザー承認済み)
- 記録は自分のものだけ。自己ベストは localStorage に保存する(キー `mogiten_gyoza_best`)。保存できなくても遊べる。サーバーは使わない。
- 作り方:Canvas 2D で自作する。ゲーム用ライブラリは重いので使わない。ゲーム部分は `next/dynamic` で、ボタンを押したときに初めて読み込む。
- 入り口:メニュー画面の上部と、待機画面の注文内容の下に「待ち時間に遊ぶ:餃子タワー」ボタンを置く。ゲームは全画面に重ねて開き、×で閉じる。ページは切り替えない。
- ルール
  1. 画面上部で餃子が左右に揺れる。タップすると落ちる。
  2. 下の餃子からはみ出した部分は切り落とされ、残った幅が次の餃子の幅になる。
  3. 重なりが 0 ならゲームオーバー。積めた個数がスコア。
  4. 5 個ごとに揺れる速さが上がる(上限あり)。
  5. ずれがごくわずかなら、ぴったりに補正する(PERFECT)。
  6. 塔が高くなると、画面が上へスクロールする。
- 呼び出しとの両立:ゲームを開いている間に注文が `ready` になったら、緑の帯で「できました! ○番 — 受け取りへ」を出す。押すとゲームを閉じる。
- 見た目:餃子キャラと同じ配色。音はなし。画面に表示していない間は描画ループを止める。
- テスト:重なりと切り落とし、速さ、揺れの往復、自己ベストの保存は、純粋関数としてテストする(`src/lib/game/`)。
